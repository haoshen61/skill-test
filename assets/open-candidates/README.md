# Open-license asset candidates

These are optional, visually reviewed derivatives sourced from Wikimedia
Commons. They contain no couple portraits, names, dates, addresses, or event
screenshots. They are kept beside the repository-generated abstract pack so a
demo can show both a generated asset path and a public-source path.

The default demo should continue using `../cover/` and `../gallery/`, because
those generated images have the most consistent beige diffusion treatment.
These candidates are not production runtime files. Before publishing one,
keep the source links in `source-metadata.json` and re-check the visual crop.

| File | Role | License |

| `cover-mistletoe.jpg` | botanical cover option | Public domain (PD-old-70 / CC-PD-Mark) |
| `share-card-floral.jpg` | square share-card option | CC0 |

| `gallery-03-prisms.jpg` | vertical gallery option | CC0 |

The files were resized/padded, re-encoded, and stripped of camera metadata.
